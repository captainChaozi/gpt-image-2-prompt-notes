把角色想法、草图、头像或吉祥物概念整理成一张结构化设定板：主头像、表情、动作姿势、道具、配色、资料卡和短标签。

## 选哪个起点

| 目标 | 模板方向 |
|---|---|
| 完整角色档案 | 角色档案海报 |
| 表情参考 | 表情九宫格 / 表情表 |
| 动作和转身 | 动作转身图 |
| 品牌形象 | 品牌吉祥物 |

| 社媒头像 | 创作者头像卡 |

## 要替换的变量

姓名、年龄或身份、性格关键词、服装方向、道具、表情列表、配色、标签语言。

## 有参考图时

上传草图或头像，可以保留身份、发型、服装方向、轮廓和关键特征，再探索新的表情、动作和版式。

## 生成后检查

面部、轮廓、表情和文字是否清晰。效果好的 prompt 保存下来，继续生成更多姿势或表情表。

适用于原创角色、吉祥物、NPC 和头像，不限于二次元风格。
