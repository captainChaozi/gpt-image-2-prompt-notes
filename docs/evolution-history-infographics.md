# 进化史信息图模板：先分 5–7 个阶段再生成

模板页：[GPT Image 2 进化史信息图模板](https://gptimage2.yfyyu.com/templates/evolution-history-infographics) · 生成器：[GPT Image 2 免费图片生成器](https://gptimage2.yfyyu.com/)

"某某的进化史"是社媒和课堂上很常见的图。这个模板的特点是：**先让 GPT Image 2 梳理结构，再画图**，避免出一条松散的时间线。

## 模板会先要求整理的内容

- 5–7 个阶段
- 关键转折点
- 每个阶段的代表物件
- 视觉阅读动线

## 示例主题

咖啡豆、游戏机、茶文化、可可、椅子、街头小吃、香水瓶。可以换成自己的主题，比如产品演化、设计史、教学海报或创始人汇报图。

## 可替换变量

| 变量 | 例子 |
|---|---|
| 主题 | 自行车、手机、汉字书写工具 |
| 时间范围 | 1800 年至今 |
| 目标受众 | 小学生、投资人、社媒读者 |
| 阶段数量 | 5 / 6 / 7 |
| 视觉风格 | 手绘、扁平、复古印刷 |
| 可见文字语言 | 中文、英文、繁中、日文等 |

## 四步流程

1. 选择最接近的示例
2. 改写标题、年代、阶段和代表物件
3. 生成第一版，检查时间线顺序、阶段层级、字体和信息密度
4. 缩短可见文字，删掉无依据的表述，再生成

## 事实要人工复核

模板强调短句和可核查标签，但 AI 生成的日期和名称仍可能出错。发布前请逐条核对年份、人名和历史表述。
