# GPT Image 2 Prompt Notes · GPT Image 2 提示词笔记

整理在 GPT Image 2 上做海报、广告图、信息图和社媒视觉时验证过的提示词结构与工作流。

- 在线试用：[GPT Image 2 免费图片生成器](https://gptimage2.yfyyu.com/)（提示词 + 参考图 + 模板，首次登录送 10 积分）
- English version: https://gptimage2.yfyyu.com/en

## 提示词六段式
1. 主体（Subject）
2. 场景（Setting）
3. 风格（Style：retro travel poster / screen print / flat infographic…）
4. 光线（Light）
5. 构图（Composition：negative space、主体位置、比例 9:16 / 3:4 / 1:1）
6. 文字（Text：内容 + 位置 + "text clear"，单独一句）

## 迭代原则
- 每次只改一个变量（构图 → 配色 → 文字）
- 参考图一次只承担一个职责（配色 / 构图 / 人物外观）
- 跑通的提示词立刻存档并打标签（用途 / 比例 / 风格）
